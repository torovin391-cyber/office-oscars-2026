# OFFICE OSCARS 2026

Готовый интерактивный сайт-приглашение на новогоднюю корпоративную церемонию 26 декабря 2026 года, 18:00 по Москве.

## Что внутри

- Кинематографическая главная сцена с раскрывающимися кулисами, золотыми софитами, красной дорожкой и статуэткой.
- Все **9 смысловых блоков** из технического задания, адаптивная типографика, навигация, анимации (включая поддержку `prefers-reduced-motion`).
- Мудборд дресс-кода из 8 подобранных фотографий с Unsplash (загружаются по HTTPS из CDN в адаптированном размере). Ссылки и сведения об источниках — в `IMAGE_SOURCES.md`.
- Рабочий таймер до `2026-12-26T18:00:00+03:00` (московский часовой пояс).
- **Форма RSVP с реальным сохранением в SQLite**: валидация, блокировка повторной отправки, идемпотентность повторных запросов, предотвращение дублирования сотрудников, запись времени в UTC и UTC+3, понятные ошибки.
- **Закрытая CSV-выгрузка** через `/admin` по административному ключу; CSV с UTF-8 BOM корректно открывается в Excel.
- Приглашение закрыто от поисковых роботов (X-Robots-Tag, robots.txt, meta noindex); дополнительный код доступа можно включить через переменную окружения.
- Иконка, готовая иллюстрация для превью в мессенджерах и автоматическая подстановка публичного URL для OG-превью.

## Запуск — без установки библиотек

Нужен **Python 3.10+**. Зависимостей от pip нет.

```bash
cd office-oscars-2026
python server.py
```

Откройте в браузере **http://127.0.0.1:8000/**. База данных создаётся автоматически в `data/rsvp.sqlite3` при первом запуске. Для проверки работы формы отправьте тестовый ответ, затем откройте `/admin` и скачайте CSV.

Если переменная `ADMIN_TOKEN` не задана, сервер при первом запуске **автоматически создаст секрет** в `data/admin_token.txt`. Это локальный секрет, **не пересылайте его сотрудникам и не публикуйте в репозитории**. У гостей нет доступа к персональным ответам.

## Размещение на сайте

Рекомендуем HTTPS-хостинг с постоянным диском для папки `data` и обратным прокси перед Python-сервером. Пример Docker-запуска:

```bash
cp .env.example .env
# отредактируйте .env
# задайте публичный адрес PUBLIC_BASE_URL и длинный ADMIN_TOKEN
docker compose up --build -d
```

Важные переменные окружения:

| Переменная | Назначение |
|---|---|
| `PORT` | Порт сервера, по умолчанию `8000` |
| `HOST` | Сетевой интерфейс; по умолчанию `127.0.0.1`, в контейнере — `0.0.0.0` |
| `DATA_DIR` | **Постоянная** папка для базы и секретов, в Docker `/data` |
| `ADMIN_TOKEN` | Секрет для доступа к CSV-экспорту через `/admin` |
| `INVITE_ACCESS_CODE` | Необязательный единый код для сотрудников; если указан, приглашение открывается только после ввода кода |
| `PUBLIC_BASE_URL` | Публичный адрес сайта с `https://`, например `https://invite.example.com`; нужен для превью ссылки |
| `SESSION_SECRET` | Необязательный секрет подписи доступа, автоматически создаётся в папке `data` |

**Важно:** до распространения ссылки проверьте форму RSVP на опубликованном сайте, сохранение записей после перезапуска сервера и скачивание CSV из `/admin`. Для резервного копирования сохраняйте весь каталог `data`. Не публикуйте `data`, файл `.env`, административный токен или экспорт CSV в открытом доступе.

**Превью в мессенджерах:** абсолютная ссылка к изображению подставляется в HTML по `PUBLIC_BASE_URL`. Мессенджерам нужен публично доступный HTTPS-адрес для предпросмотра, даже если само приглашение закрыто кодом. При включённом коде доступа страница ввода кода также содержит Open Graph-метатеги с тем же оформлением превью. Мессенджеры смогут показать картинку и название приглашения, не открывая содержимое сайта.

**Приватность:** `noindex` и непредсказуемая ссылка помогают ограничить распространение, но сами по себе не являются авторизацией. Для действительно закрытого приглашения включите `INVITE_ACCESS_CODE` и HTTPS.

## Структура

- `server.py` — HTTP-сервер, SQLite, RSVP API, выгрузка CSV, ограничения запросов.
- `static/index.html` — содержание и разметка приглашения.
- `static/styles.css` — дизайн, адаптивная сетка, анимации.
- `static/app.js` — обратный отсчёт, анимации, отправка формы.
- `static/admin.*` — закрытый интерфейс для выгрузки.
- `static/unlock.*` — экран ввода кода закрытого приглашения.
- `static/og-preview.png`, `static/favicon.svg`, `static/statuette.svg` — визуальные элементы.
- `Dockerfile`, `compose.yaml` — контейнерное развёртывание.

**Что нельзя получить автоматически из архива:** публичную ссылку в интернете — для неё нужен хостинг и домен. Проект готов к запуску и реальному сохранению ответов после размещения на сервере.
